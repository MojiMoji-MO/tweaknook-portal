How to Fix Bluetooth Missing from Windows 11

Published on August 2, 2026 • By Tweaknook Editorial

If Bluetooth is missing from Windows 11 Settings, Quick Settings, or Device Manager, begin by deciding whether the radio is merely hidden or Windows has stopped detecting the adapter. A missing Quick Settings tile alone is usually a layout issue. A missing Bluetooth switch under Settings > Bluetooth & devices points instead to a driver, service, update, or hardware-detection problem.

The safest repair order is to restart Windows, turn off Airplane mode, run the Bluetooth troubleshooter, install Windows and optional driver updates, and then inspect Device Manager. Reinstalling a driver or using System Restore should come later, after you have identified the adapter and saved the correct manufacturer driver.

First Identify What Is Actually Missing

Open Settings > Bluetooth & devices. If the Bluetooth switch is present there but the tile is absent when you press Windows + A, Windows is still detecting the adapter. Customize Quick Settings rather than removing drivers. Microsoft notes that the Bluetooth action may need to be added when it is not visible in Quick Settings.

If the switch is absent from Settings, open Device Manager by right-clicking Start and selecting Device Manager. Look for a Bluetooth category and for entries that include the adapter manufacturer's name or the word “radio.” The result determines the next step:

  • Bluetooth appears normally: the adapter is detected; update it and check the service before reinstalling anything.
  • Bluetooth appears with a warning symbol: open the adapter's Properties window and read the device status before choosing a repair.
  • The Bluetooth category is missing: scan for hardware changes, check hidden devices, and confirm that the PC actually includes Bluetooth hardware.
  • A USB Bluetooth adapter is used: reconnect it directly to another USB port and check whether Windows detects the USB device.

Do not confuse this symptom with a headset or mouse that will not pair. When the Bluetooth switch is visible and the adapter appears in Device Manager, use connection-specific troubleshooting instead of removing the adapter.

Restart Windows and Check Airplane Mode

Save your work and choose Start > Power > Restart. Use Restart rather than Shut down so Windows closes the current session and reloads drivers and services. After signing in, press Windows + A and make sure Airplane mode is off. Microsoft lists both actions among the first checks for Bluetooth that has disappeared.

Return to Settings > Bluetooth & devices. If the switch has returned, turn Bluetooth off and on once, then test with one known device. If the switch is still missing, continue without repeatedly restarting or changing unrelated network settings.

Run the Windows 11 Bluetooth Troubleshooter

Microsoft directs Windows 11 users to the automated Bluetooth troubleshooter in the Get Help app. Open Start, search for Get Help, and search inside the app for Bluetooth troubleshooting. Follow the prompts and note what the diagnostic reports.

The troubleshooter can check common configuration and service problems, but it cannot repair absent hardware or guarantee that a manufacturer driver is compatible. After it finishes, restart only if requested, then confirm whether the Bluetooth switch and the Device Manager category have returned.

Install Windows Updates and Optional Driver Updates

Open Settings > Windows Update, select Check for updates, and install available updates. Restart when required. Some Bluetooth drivers arrive through Windows Update, so this step is more useful than downloading a driver from an unofficial driver site.

Next open Settings > Windows Update > Advanced options > Optional updates. Expand Driver updates if it is available. Install a Bluetooth, wireless, or system-device driver only when it matches the hardware in your PC. Optional drivers are not installed automatically, and the page may be empty.

Read the Adapter Status in Device Manager

Open Device Manager again and expand Bluetooth. Right-click the main Bluetooth adapter, not each paired headset or mouse, and select Properties. The General tab shows whether Windows reports that the device is working or provides an error code.

If Enable device is available in the right-click menu, select it and restart the PC. If the adapter is already enabled, choose Update driver > Search automatically for drivers. Windows may report that the best driver is already installed; that message only describes the drivers Windows found, not every driver published by the PC manufacturer.

When the Bluetooth category is absent, open Device Manager's View menu and select Show hidden devices, then use Action > Scan for hardware changes. A faded entry can represent hardware that is not currently connected or detected. Do not uninstall every faded Bluetooth item. First identify the actual adapter from the PC manufacturer's specifications or support page.

Install the Driver from the PC Manufacturer

Use the support page for the exact laptop, motherboard, or prebuilt desktop model. Enter the serial number or model identifier when the manufacturer provides that option, select Windows 11, and download the current Bluetooth driver. A Wi-Fi/Bluetooth combination card may have separate wireless and Bluetooth packages.

Avoid generic “driver updater” programs and download sites. They can offer a package for a similar chipset that does not match the computer manufacturer's configuration. Keep the downloaded installer until Bluetooth is working so you can repeat the installation after a rollback or driver removal.

Install the manufacturer package, restart Windows, and check both Settings and Device Manager. If the manufacturer does not list a Windows 11 Bluetooth driver for the model, do not force a package intended for a different computer. Contact the manufacturer to confirm support.

Restart the Bluetooth Support Service

If Device Manager detects the adapter but the Settings switch remains unavailable, press Windows + R, enter services.msc, and select OK. Find Bluetooth Support Service, right-click it, and choose Restart. Then reopen Bluetooth settings.

Do not change several service startup types at random. Managed work or school computers may enforce service settings through policy, and changing them can create a separate support problem. If Restart is unavailable or access is denied, contact the device administrator.

Reinstall the Bluetooth Adapter Only After Preparing the Driver

Driver reinstallation is appropriate when the adapter appears in Device Manager but updating it does not restore Bluetooth. Before removing it, save the manufacturer driver installer, close open work, and create a backup of important local files. For a separate copy of critical folders, the cautious workflow in How to Create a Safer One-Way Backup with Robocopy explains how to preview a backup before running it.

  1. In Device Manager, expand Bluetooth and identify the main adapter.
  2. Right-click the adapter and select Uninstall device.
  3. Confirm the uninstall. Do not select an option to remove the driver package unless the manufacturer specifically instructs you to and you have the replacement installer.
  4. Restart Windows. Windows will attempt to reinstall the device driver.
  5. If the adapter does not return, open Device Manager and select Action > Scan for hardware changes, then run the saved manufacturer installer.

Check Settings after the restart. If the adapter now appears but a particular device will not connect, the missing-Bluetooth problem is resolved and the remaining issue is pairing, range, battery, or device compatibility.

Decide Whether the Problem Is Hardware-Related

Some desktops and older PCs do not include Bluetooth. Microsoft notes that a missing Bluetooth setting can mean there is no adapter, or that its driver is not installed. Check the manufacturer's original specifications rather than assuming every Windows 11 PC has Bluetooth. A compatible USB Bluetooth adapter can add the feature to a computer that never included it.

If Bluetooth worked before but remains absent after updates, a manufacturer driver, a restart, and a hardware scan, stop repeating software fixes. Check for a physical wireless switch, recent damage, or a USB adapter that fails in more than one port. The checks in How to Fix a USB Drive That Is Not Showing Up in Windows 11 can help distinguish a port problem from a device problem.

Contact the PC or adapter manufacturer when the device repeatedly reports a hardware error, disappears after every restart, is missing from the manufacturer's diagnostics, or is still under warranty. On a company or school computer, contact the administrator before installing drivers or changing services.

Use System Restore Only for a Clear Recent Change

If Bluetooth disappeared after a recent driver, app, or settings change and a restore point exists, System Restore can return system files and settings to an earlier state without targeting personal files. It can remove recent apps, drivers, or settings, so review affected programs and back up important work first.

Do not reset or reinstall Windows merely because the Bluetooth tile is missing. Microsoft treats reset and reinstallation as broader recovery options that can remove applications, settings, or data depending on the choice. Use them only when Windows has wider problems and after a verified backup, not as the next Bluetooth step.

What Not to Do

  • Do not install drivers from an unrelated PC model or a third-party driver bundle.
  • Do not delete registry keys or system driver files from an unverified tutorial.
  • Do not uninstall every hidden Bluetooth device without identifying the adapter.
  • Do not reset Windows before checking hardware support, updates, drivers, and services.
  • Do not assume a missing Quick Settings tile means the Bluetooth hardware has failed.

Confirm That Bluetooth Is Restored

The repair is complete when the Bluetooth switch appears under Settings > Bluetooth & devices, the adapter appears without an error in Device Manager, and Windows can discover or connect to a known Bluetooth device. Restart once more and confirm that the switch remains available after sign-in.

If the switch returns but audio cuts out or a device repeatedly disconnects, troubleshoot that connection separately. If the switch disappears again after a specific update, record the update date, adapter model, driver version, and Device Manager status before contacting Microsoft or the manufacturer. Those details make the next diagnosis more useful than repeating driver removal.

Use the Symptom to Choose the Repair

A missing tile, a missing Settings switch, and an adapter absent from Device Manager are different problems. Start with the least destructive check that matches what Windows can still detect. If the adapter remains absent after the correct updates and manufacturer driver, investigate hardware or policy rather than escalating to risky system changes.
