Windows Clipboard History: Paste, Pin, and Clear Multiple Items

Published on July 9, 2026 • Updated on September 30, 2026 • By Tweaknook Editorial

Press Windows + V to open Clipboard History. If it is disabled, select Turn on. You can then paste a previous item, pin a reusable item, or remove entries that should not remain. Clipboard History is a short-term convenience buffer, not secure or permanent storage.

Distinguish the three clipboard features

FeatureWhat it doesMain caution
Current clipboardHolds the most recently copied item for ordinary pasteAnother copy replaces it
Clipboard HistoryLets you choose from recent supported items with Windows + VCapacity and item-size limits apply
Sync across devicesCan make supported clipboard content available on other signed-in devicesAccount, device, policy, and privacy settings matter

What Clipboard History keeps

Microsoft currently documents up to 25 copied entries, a 4 MB per-item limit, and support for text, HTML, and bitmap content in history. Older unpinned entries are removed as new ones arrive. Large objects or unsupported formats may never appear.

Paste an earlier item

  1. Copy several short pieces of harmless text.
  2. Press Windows + V.
  3. Select the item you want.
  4. Confirm it was pasted into the intended field or application.

If the panel opens but shows no history, confirm the feature is on under Settings > System > Clipboard.

Pin only stable, non-sensitive snippets

Use an item's menu to pin text you want to keep. Microsoft notes that a restart clears unpinned history but preserves pinned entries. That persistence is useful for a harmless template and risky for a password, authentication code, recovery phrase, private customer detail, or temporary secret.

Review sync before enabling it

Clipboard synchronization is separate from local history. It uses the account and devices allowed by Windows and may be unavailable or controlled on a managed computer. If you need it, enable it with harmless text first, confirm the expected account and devices, and review whether automatic or manual synchronization is offered in the current Windows build.

Clear sensitive entries correctly

Delete an individual item from Windows + V or use the Clipboard settings clear control. Review pinned entries separately because a general clear action may not remove them. Clearing the Windows clipboard also does not erase content already pasted into a document, sent in a message, saved by another application, or synchronized by a different clipboard tool.

Why an item may be missing

  • It exceeded the supported size.
  • Its format is not kept in history.
  • The history reached its entry limit and the item was not pinned.
  • The computer restarted and the item was not pinned.
  • Clipboard History is off.
  • An organization policy controls the feature.
  • The source application copied a format that another application handles differently.

Test the feature without exposing real data

Copy three labels such as alpha, beta, and gamma. Open Windows + V and paste the middle item. Pin one harmless label and verify that you understand the pin and delete controls. Do not use a real password or client record as a diagnostic sample.

When Clipboard History is the wrong tool

Use a password manager for credentials, a snippet manager for an organized text library, and a document or template system when versioning, permissions, audit history, or long-term retention matters. Clipboard History is intentionally limited.

Completion check

  • Windows + V opens the history panel.
  • A selected earlier item pastes correctly.
  • Pinned and unpinned behavior is understood.
  • Sync is either intentionally configured or left off.
  • Sensitive test data has been removed.
