How to Fix Wi-Fi That Keeps Disconnecting on Windows

Published on July 27, 2026 • By Tweaknook Editorial

Intermittent Wi-Fi is harder to diagnose than a connection that never works. The computer may stay online for twenty minutes, disconnect during a video call, reconnect by itself, and then fail again in another room. Repeating random fixes can hide the pattern without identifying the cause.

A reliable troubleshooting process starts by separating four possible problem areas: the Windows PC, the wireless signal, the router or access point, and the internet service. The steps below move from low-risk checks to deeper resets. Stop when the connection remains stable; there is no benefit in changing driver, router, and network settings after the problem has already been resolved.

First, Identify the Scope of the Drop

When the connection fails, check another phone or computer on the same Wi-Fi before restarting anything. This single comparison determines which branch of troubleshooting is most useful.

What happens Most likely area Start with
Only one Windows PC disconnects Saved network profile, adapter, driver, VPN, or power setting Forget and reconnect, then check Windows and driver updates
Every device disconnects at the same time Router, modem, power, or internet service Restart network equipment and check the provider's status
The PC disconnects only far from the router Signal strength, obstacles, or frequency band Test closer to the router and compare available bands
Wi-Fi stays connected but websites stop loading Internet service, DNS, VPN, proxy, or one application Test another website and another device before resetting Wi-Fi
Only one browser or application fails Application, extension, firewall, or VPN configuration Test a second application on the same PC

If Chrome is slow but another browser and a speed test work normally, the connection may not be the problem. Use Chrome Task Manager and Memory Saver to check whether a tab or extension is consuming resources.

Record One Failure Before Changing Settings

A short record makes intermittent problems easier to compare. Note the exact time of the drop, the room, whether the laptop was using battery power, the Wi-Fi network name, and whether another device also lost access. If the issue happens only after sleep, only on battery, or only in one location, that detail should guide the next step.

Do not publish screenshots or diagnostic reports without reviewing them. Network reports can contain computer names, adapter identifiers, Wi-Fi profile names, IP configuration, and other details that are useful for support but unnecessary to share publicly.

Step 1: Run the Windows Network Troubleshooter

On Windows 11, open Get Help and run the Network and Internet troubleshooter. It can check common adapter and connection conditions without changing unrelated files or applications.

After the troubleshooter finishes, write down any error or recommendation it displays. Test the connection in the same place and under the same conditions that usually trigger the drop.

Step 2: Forget and Reconnect to the Network

A saved Wi-Fi profile contains the network name, security details, and connection preferences. Recreating that profile is a reasonable early step when one PC has trouble but other devices remain stable.

  1. Open Settings.
  2. Select Network & internet.
  3. Select Wi-Fi.
  4. Open Manage known networks.
  5. Select the affected network and choose Forget.
  6. Reconnect from the Wi-Fi list and enter the current password.

Before forgetting a network, confirm that you know its password. On work, school, hotel, or certificate-based networks, reconnecting may require instructions from the network administrator.

Step 3: Restart the PC and Network Equipment Separately

Restart the Windows PC first. If only that device was affected and the connection remains stable afterward, do not reboot the router.

If several devices are affected, restart the modem and router according to the manufacturer's instructions. A common sequence is to disconnect power, wait at least thirty seconds, power the modem first, wait for its status lights to settle, and then power the router. A combined modem-router unit requires only one restart.

Restarting equipment temporarily disconnects everyone using the network. Avoid doing it during another person's call, file transfer, remote session, or online transaction.

Step 4: Compare Wi-Fi Bands and Distance

Many routers offer 2.4 GHz and 5 GHz networks, while newer equipment may also provide 6 GHz. The strongest option depends on distance, walls, interference, and device support.

  • 2.4 GHz: Usually reaches farther and passes through obstacles better, but it can be more congested.
  • 5 GHz: Often provides higher throughput with less congestion, but its useful range is shorter.
  • 6 GHz: Can perform well near a compatible router, but both the router and device must support it and the range is shorter.

If the connection drops in a distant room, test 2.4 GHz. If it drops near the router in a busy area, compare 5 GHz. Some routers combine bands under one network name and choose automatically; consult the router documentation before changing band-steering or channel settings.

Do not change several router settings at once. Record the original value, make one change, and retest in the same location. This preserves a clear path back if reliability becomes worse.

Step 5: Check Windows Update and the Wi-Fi Driver

Open Settings → Windows Update and install applicable updates. Restart the PC when Windows requests it.

If the issue started after a driver or Windows update, identify the Wi-Fi adapter before replacing anything:

  1. Open Device Manager.
  2. Expand Network adapters.
  3. Open the properties for the wireless adapter.
  4. Review the Driver tab for the provider, date, and version.

Windows Update can supply recommended and optional drivers. If it does not provide a suitable driver, use the support page for the PC or adapter manufacturer and select a driver that matches the exact model and Windows version.

Avoid driver-download sites that are not operated by Microsoft, the PC manufacturer, or the adapter manufacturer. Before uninstalling an adapter driver, download a known-compatible installer or confirm that another device and a USB drive are available. Windows often reinstalls the adapter after a restart, but keeping a backup prevents a failed recovery from leaving the computer offline.

Step 6: Test the Adapter Power Setting

This check is most relevant when Wi-Fi drops after sleep, when the laptop changes to battery power, or after a period of inactivity.

  1. Open Device Manager.
  2. Expand Network adapters.
  3. Open the wireless adapter's properties.
  4. If a Power Management tab is available, clear Allow the computer to turn off this device to save power.
  5. Select OK and restart the PC.

Not every adapter exposes this option. If the tab is absent, do not install registry tweaks or unrelated utilities to force it to appear. Continue with the next diagnostic step.

Step 7: Generate a Wireless Network Report

Windows can create an HTML report containing Wi-Fi events from the previous three days, connection sessions, adapter details, and recorded disconnection reasons. This is more useful than guessing when the problem is intermittent.

  1. Search for Command Prompt.
  2. Select Run as administrator.
  3. Enter the following command:
netsh wlan show wlanreport

Windows displays the location of the generated HTML file. Open it in a browser and review the summary chart, session failures, disconnect reasons, adapter driver version, and the times that match your notes.

The report does not display Wi-Fi security keys in readable form, but it still contains system and network details. Share only the relevant error text with a trusted support technician rather than uploading the complete report to a public forum.

Step 8: Separate Router Access from Internet Access

A PC can remain connected to the router while the router has lost access to the internet. Windows may show a Wi-Fi connection with a no-internet status in this situation.

Use this comparison:

  1. Check whether another device on the same Wi-Fi can open several unrelated websites.
  2. Check the modem or router status lights and the provider's service-status page.
  3. Temporarily disconnect a VPN and retest only if doing so is allowed by your organization.
  4. Check whether a manual proxy is configured under Settings → Network & internet → Proxy.

If every device loses internet while remaining connected to the router, the Windows adapter is unlikely to be the primary cause. Contact the internet provider or router manufacturer with the failure times and status-light behavior.

Step 9: Use Network Reset Only as a Last Step

Network reset removes installed network adapters and returns their settings to defaults before Windows reinstalls them after a restart. It can also require VPN clients, virtual switches, custom DNS settings, and network profiles to be configured again.

Before using it:

  • Save Wi-Fi passwords and organization-specific setup instructions.
  • Record VPN and proxy settings.
  • Confirm that you can sign back into required accounts.
  • Close work and save open files.

On Windows 11, open Settings → Network & internet → Advanced network settings → Network reset. Select Reset now only after the earlier steps have failed.

After the restart, known networks may need to be rejoined and a network may be classified as public. Review the network profile and file-sharing settings before using shared folders or printers.

When to Stop Troubleshooting the PC

Escalate the problem to the router manufacturer, internet provider, device manufacturer, or network administrator when:

  • Several devices disconnect at the same time.
  • The router restarts, overheats, or shows abnormal status lights.
  • The connection fails only on a managed work or school network.
  • The wireless adapter disappears from Device Manager.
  • The problem began after hardware damage or liquid exposure.
  • A compatible manufacturer driver does not restore the adapter.
  • The wireless report repeatedly records the same adapter or authentication error.

For remote access, confirm that local Wi-Fi is stable before troubleshooting the remote-access application itself. The guide on accessing a PC remotely with Tailscale explains why connection quality still depends on both networks.

A Short Diagnostic Order

  1. Check whether one device or every device disconnects.
  2. Record the time, location, power state, and affected applications.
  3. Run the Windows troubleshooter.
  4. Forget and reconnect to the Wi-Fi network.
  5. Restart the affected device; restart the router only when the network is affected.
  6. Compare bands and test closer to the router.
  7. Install appropriate Windows and manufacturer driver updates.
  8. Check adapter power management when the pattern supports it.
  9. Generate a wireless network report.
  10. Use network reset only after saving network and VPN settings.

This order preserves evidence and limits unnecessary changes. It also makes it easier to explain the problem accurately if outside support is needed.
