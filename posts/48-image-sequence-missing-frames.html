Missing Frames in an Image Sequence: Check Numbered Files Before Import

Published on October 24, 2026 • Updated on October 24, 2026 • By Tweaknook Editorial

A numbered image sequence can fail during import even when a folder looks nearly complete. Start by separating missing filename numbers from files that exist but cannot be read, and from files that an editor groups into the wrong sequence. Those are different problems. A filename check can reveal missing-number candidates and inconsistent grouping patterns, but it cannot verify file readability, inspect image pixels, or repair a missing frame.

Before you re-render or rename anything, make a copy of the folder and define the expected frame range. Then compare the actual filename list with that expectation. This is useful for animation frames, exported PNG sequences, VFX passes, and other numbered still-image deliveries.

Begin with the symptom, not the filename

Import symptomLikely area to inspectWhat a filename-only check cannot decide
Editor reports a missing frame within a sequenceNumeric gap, path availability, import settingsWhether an existing image file is readable
Files import as separate stillsFilename pattern and sequence optionWhether the editing app supports that image format
A sequence stops sooner than expectedExpected end frame, source export range, numberingMissing frames beyond the highest number present
The wrong take or pass appears in one sequencePrefix, folder, extension, multiple sequencesWhether two images depict different content
All expected names exist, but import still failsFile integrity, storage access, format, application errorThe integrity of the image contents

Do not assume every two-number jump is an error. Some workflows intentionally render every second or fifth frame. The intended interval comes from the job specification, export settings, or delivery notes—not from the names alone.

A small frame list that makes the gap visible

Consider these illustrative filenames for one PNG render pass:

sceneA_0100.png
sceneA_0101.png
sceneA_0103.png
sceneA_0104.png

If the intended step is one frame, 0102 is a missing-number candidate between two existing files. However, the list cannot establish whether frames 0099 or 0105 should also exist; it has no knowledge of the required start or end frame. That is why the delivery range matters.

Now compare a different list:

sceneA_0100.png
sceneA_0102.png
sceneA_0104.png

If this is a planned every-other-frame export, the spacing is deliberate. Treating 0101 and 0103 as necessarily lost would invent a problem. A checker may infer an interval from a few names, but it cannot replace the production specification.

The pre-import audit: six decisions

  1. Preserve your source. Copy the folder or use a read-only inspection workflow. Do not batch-rename the only copy, especially if an existing project already links to it.
  2. Define one pass. Keep sceneA_beauty_, sceneA_depth_, and other render passes separate. A same-looking number can legitimately exist in each pass.
  3. Record the expected range and step. For example, frames 0100–0104 at step 1 have five expected positions. That count assumes the range is inclusive and no deliberate skip exists.
  4. Compare actual numbers in that family. Look for interior gaps, repeated sequence positions, unexpected padding width, and files that use a different extension or naming pattern.
  5. Check the flagged source files. Confirm with the render log or source application whether a missing number represents a failed render, an intentional omission, or a different output directory.
  6. Import a verified copy. Use the receiving application's documented sequence settings and inspect the resulting duration and frames before relying on the sequence downstream.

The order matters. Renaming every file to make the numbers look continuous can hide an incomplete render instead of fixing it.

Check a larger filename list with SeqName

For a folder with many numbered stills, SeqName's filename sequence checker can shortlist the names that deserve attention. Choose related files or a folder, run the check, and review its gap, duplicate, zero-padding, extension, and pattern findings. The page also offers CSV and JSON report exports for documenting the review.

SeqName uses selected filenames and relative folder paths. It does not read the image content, upload the selected files as part of its analysis, create replacement frames, or rename anything automatically. The report is a list of filename-based candidates, not a declaration that footage is visually complete.

To interpret the sample above, compare the expected step of 1 and candidate gap 0102 with the original export range. If you have several numeric tokens such as shot03_v02_frame0100.exr, first establish which token counts frames. That separate decision is covered by Which Number Is the Sequence? Auditing Filenames with Dates, Versions, and Frame Numbers.

Check the importing application next

Adobe's After Effects documentation says that a still-image sequence should use files in the same folder with a consistent numeric or alphabetic naming pattern. If files do not group as expected, check the Sequence option in the Import dialog before renaming the originals.

Adobe also documents Force alphabetical order as an import option for sequences whose numbering has gaps. That can change how files are brought in; it does not recreate missing source frames. Depending on import settings, After Effects may warn about missing frames and show placeholders. If an expected file seems present but unavailable—for example, a broken shortcut or offline storage—Adobe documents a slower Verify Individual Files option for sequence imports.

These are After Effects-specific controls, not universal settings for every video editor. Confirm the current labels in the version you are using. Do not change the underlying filenames just to match a menu option you saw in a different application.

If your next step is an FFmpeg image-sequence import, the file pattern matters too. FFmpeg's own FAQ shows that img%03d.jpg addresses three-digit names like img001.jpg, and its documentation describes -start_number for ranges that do not begin at the default number. A naming mismatch and a genuinely missing image are not the same fault. Validate the actual folder names before building an import command.

What to do with each finding

  • Interior gap confirmed: ask for the missing render or regenerate the specific frame if the source project permits it. Do not silently shift later frame numbers.
  • Possible duplicate number: check whether the files belong to different passes, cameras, directories, or formats. A repeated number is not proof of duplicate image content.
  • Mixed padding such as 099 and 0100: decide the intended naming width, preview a rename plan on a copy, and check whether downstream projects rely on the old paths.
  • Missing expected first or last frame: compare the export log or delivery manifest. A checker cannot infer filenames that lie outside the observed range.
  • All numbers present, import fails: inspect storage access, file readability, supported image format, and the importing application's diagnostics. Filename analysis has reached its limit.

Keep the check report beside the source range and any render/export notes. A useful delivery note states: pass, expected first/last frame, step, detected filename candidates, reviewed exceptions, and whether the import was successfully checked in the receiving app.

Ready to import?

A sequence is ready for the next stage when you can explain its numeric range, intended interval, pass grouping, known gaps, and destination application's behavior. If an exception remains, mark it explicitly rather than hiding it through a rename. For a general audit of numbered files outside image/video work, see Missing or Duplicate Filename Numbers: A Safe Sequence Audit.
