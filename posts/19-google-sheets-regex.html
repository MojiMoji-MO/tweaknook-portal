How to Clean Messy Spreadsheet Data with Google Sheets Regex

Published on July 16, 2026 • Updated on August 17, 2026 • By Tweaknook Editorial

Use Google Sheets regex functions in a new helper column, not directly over the source data. Keep the original value, write a formula that extracts or normalizes one pattern, and create a review column for rows that do not match. Only replace the source after the cleaned results have been checked.

Know which regex function solves which problem

  • REGEXEXTRACT returns the first matching substring. Capture groups can return multiple columns.
  • REGEXREPLACE replaces all parts of the text that match the expression.
  • REGEXMATCH returns TRUE or FALSE and is useful for a validation flag.

Google Sheets uses the RE2 regular-expression engine, with documented limitations including Unicode character-class matching. A pattern copied from another regex engine may therefore need adjustment.

Example: extract a simple email-like value

Suppose column A contains notes such as Contact: alex@example.com (preferred). A helper-column formula can extract an email-shaped substring:

=IFERROR(REGEXEXTRACT(A2,"[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}"),"")

This is a pattern-cleaning example, not a guarantee that the extracted address exists or can receive mail. Keep a review flag for blank results or rows containing multiple possible addresses.

Example: normalize phone text without claiming a country format

If the goal is simply to retain digits from a phone field, use:

=REGEXREPLACE(A2,"[^0-9]","")

This removes punctuation, spaces, and symbols. It does not determine the correct country code, extension, or national numbering format. Do not add or remove a leading digit unless you have a separate rule for the dataset's region.

Example: detect rows that need manual review

=NOT(REGEXMATCH(A2,"^[A-Z]{3}-[0-9]{5}$"))

For an identifier that is supposed to look like ABC-00123, TRUE from the formula above can mean “review this row.” A validation flag is often safer than trying to repair every unexpected value automatically.

Remember that REGEXEXTRACT returns the first match

If a cell contains several numbers or addresses, REGEXEXTRACT does not automatically return every match. Google's documentation explicitly describes it as extracting the first matching substring. When multiple values matter, redesign the formula or workflow rather than assuming the first match is representative.

Use capture groups deliberately

Capture groups can split a structured value into multiple outputs. For an identifier such as INV-2026-00125, a pattern can capture the year and sequence separately. Test the pattern on valid examples and on malformed examples before filling it down a production column.

Do not convert identifiers into numbers by accident

Regex functions work with text. If a cleaned result is an identifier such as 00123, keep it as text when the leading zeros are meaningful. How to Stop Google Sheets from Changing Numbers to Dates explains how to protect identifier-like text before entry or paste.

A safer cleanup workflow

  1. Duplicate the sheet or preserve the raw source column.
  2. Write the regex formula in a helper column.
  3. Test known valid, invalid, blank, and unusual values.
  4. Add a review flag for errors or unexpected patterns.
  5. Count blanks and exceptions before and after cleanup.
  6. When the result is verified, paste values into a new final column if a static result is required.

Completion check

Sample records from across the dataset, not only the first few rows. Compare the cleaned value to the original and confirm that the transformation did not discard meaningful punctuation, leading zeros, non-English characters, extensions, or multiple values that the business process needs.
