How to Fix Microsoft Store Stuck on Pending in Windows 11

Published on August 5, 2026 • By Tweaknook Editorial

If Microsoft Store downloads stay on Pending, first determine whether one app is blocked or the entire queue has stopped. For all-app failures, restart the Store and Windows, install Windows updates, update Microsoft Store, run wsreset.exe, and repair the Store app before using Reset. For one-app failures, check the app's region, account, family, device, and Windows compatibility instead of resetting the whole Store immediately.

Do not delete Windows app folders, paste an unverified PowerShell re-registration command, or reset Windows as an early fix. Those steps can create a larger problem without explaining whether the cause was the Store cache, a pending restart, insufficient storage, account restrictions, or an unavailable app.

Identify Which Microsoft Store Problem You Have

Open Microsoft Store and go to Library or the current downloads and updates view. The label can change with Store updates, but the distinction below determines the safest repair:

  • Every download is Pending: focus on Windows updates, the Store app, its cache, the network, and available disk space.
  • Only one app will not install: check compatibility, region availability, family restrictions, ownership, and whether the publisher removed the app.
  • Microsoft Store will not open: clear its cache, check Windows updates, time, and region, then repair the Store app.
  • An installed app will not update: confirm the Store itself is updated, then repair or reinstall only that app if needed.
  • A work or school device has no Store access: an administrator may have disabled it; do not try to bypass the policy.

Record any displayed error code before changing settings. A code is more useful to Microsoft Support than the general message “download not working,” and it helps distinguish an account problem from a device or service problem.

Close the Store, Restart Windows, and Recheck the Queue

Close Microsoft Store with the X button. Save other work, then choose Start > Power > Restart. A restart matters after Windows updates because Microsoft notes that a recently updated PC may need to restart before Store apps can install.

After signing in, open Microsoft Store and return to Library. If a single item is still stuck and the current interface provides a cancel control, cancel only that item and start it again. Avoid canceling a paid order or removing several working downloads when only one package is blocked.

Confirm the Microsoft Account and App Availability

Open the Store profile menu and verify that you are signed in with the Microsoft account that owns the app or purchase. A Windows local account and the Microsoft account used inside Store are not always the same.

When only one app is affected, check its Store page for an Install button, compatibility notice, age restriction, or device limitation. Microsoft lists several reasons an app may not be available:

  • The app is not offered in the current country or region.
  • Microsoft Family settings hide or restrict it.
  • The app has been removed from Store.
  • The app is incompatible with the device.
  • The PC is not authorized for the relevant Store account or purchase.

Do not change the Windows region merely to obtain an app that is not licensed for your location. If a purchased item is missing, review the order history for the account used to buy it or contact Microsoft Support.

Install Windows Updates and Restart

Go to Settings > Windows Update and select Check for updates. Install available updates and restart when requested. Microsoft places Windows Update near the beginning of its official Store-app troubleshooting sequence.

Return to Windows Update after the restart and confirm that no update is waiting for another restart. If Windows Update itself fails, resolve that problem first because Store downloads can remain queued while Windows servicing is incomplete. The Get Help app includes a Windows Update troubleshooter for this situation.

Update Microsoft Store Itself

Open Microsoft Store and select Library, then choose Get updates or Check for updates, depending on the current Store version. Microsoft says Store updates normally install automatically, but manually checking can update the Store before it processes the stalled app queue.

Wait for Store's own update to finish before retrying several large apps. If the Store closes during its update, reopen it and check Library again.

Check the Connection and Available Disk Space

Open a normal website to confirm that the PC has a working internet connection. If Wi-Fi drops repeatedly, fix the connection before repeatedly restarting Store downloads. How to Fix Wi-Fi That Keeps Disconnecting on Windows separates PC, router, signal, and internet-service problems.

Next open Settings > System > Storage and check free space on the Windows drive. An app can need more temporary space than its displayed download size. Use Storage settings and Cleanup recommendations before manually deleting folders. The safer cleanup order is covered in How to Free Up Disk Space Safely in Windows.

Avoid deleting WindowsApps, Program Files, or unfamiliar package folders. Changing ownership or removing package files can break existing apps and does not address account or Store-service problems.

Reset the Microsoft Store Cache with wsreset.exe

Microsoft provides wsreset.exe to clear the Store cache without requiring a third-party cleaner.

  1. Press Windows + R.
  2. Enter wsreset.exe.
  3. Select OK.
  4. Wait while a blank Command Prompt window opens.
  5. When the window closes and Microsoft Store opens, check Library again.

Microsoft says the blank window normally closes after about ten seconds. Do not close it immediately because it may still be completing the cache reset. If Store does not reopen, launch it from Start and continue with app repair.

Repair Microsoft Store Before Resetting It

Repair is the safer next step because Windows describes it as an attempt to fix an app without reinstalling it.

  1. Open Settings > Apps > Installed apps.
  2. Find Microsoft Store.
  3. Select the three-dot menu, then Advanced options.
  4. Select Repair.
  5. Open Store and test one download.

If Repair is not displayed in your Windows build, continue with the options that are available rather than following a menu path from an older tutorial.

Use Reset Only If Repair and Cache Clearing Fail

Return to Settings > Apps > Installed apps > Microsoft Store > Advanced options and select Reset. Windows warns that Reset returns an app to its default state and may remove its app data. Be prepared to sign in to Store again and recheck the account afterward.

Resetting Microsoft Store is not the same as resetting Windows. Do not use Reset this PC for an isolated Store queue unless Windows has broader problems and important files are backed up.

Use Get Help for Windows Update or BITS Problems

If all downloads remain pending after Store repair, open the Get Help app. Microsoft currently provides troubleshooters there for Windows Update and Background Intelligent Transfer Service (BITS). Search for the relevant troubleshooter, allow the diagnostic when prompted, and follow only the findings that match the PC.

Do not randomly disable, rename, or change the startup type of Windows services. On managed devices, service settings may be enforced by policy. If Get Help reports a service or policy problem you cannot change, contact the administrator or Microsoft Support.

When Only One App Still Will Not Download

When other apps install normally, the Store infrastructure is probably working. Return to the affected app's page and check:

  • Whether the app supports the installed Windows version and hardware.
  • Whether the publisher has replaced it with a different listing.
  • Whether the account owns the paid app.
  • Whether family or organization controls block it.
  • Whether its required device type or regional availability matches the PC.

For an app that is officially available through Windows Package Manager, WinGet can be an alternative installation path after you verify the exact publisher and package ID. It is not a workaround for paid licenses, family controls, or organization policy. How to Install Multiple Windows Apps with WinGet explains how to verify package IDs before installation.

What Not to Do

  • Do not download a modified Microsoft Store installer from an unofficial site.
  • Do not paste a long PowerShell re-registration command without understanding which packages it changes.
  • Do not delete the WindowsApps folder or take ownership of protected app folders.
  • Do not reset Windows before trying the Store-specific cache, repair, and account checks.
  • Do not bypass family, region, purchase, or workplace restrictions.

Confirm That Microsoft Store Is Working Again

Use a small free app or an available update as a controlled test. The repair is successful when the item moves from Pending to Downloading, completes installation, and opens normally. Then return to the original app.

If the queue fails again, record the time, Store account, app name, Windows version, available storage, network type, and exact error code. Contact Microsoft Support when purchases are missing, Store repeatedly resets, Get Help reports an unresolved servicing problem, or the device is managed by an organization.

Use the Smallest Repair That Matches the Failure

Fix one-app availability problems at the app and account level. Fix an all-app Pending queue with updates, a restart, Store updates, cache clearing, Repair, and only then Reset. This order preserves working apps and settings while giving each change a clear result you can verify.
