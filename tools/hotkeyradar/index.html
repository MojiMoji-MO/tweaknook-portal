How to use the shortcut conflict checker

  1. Choose an operating system and browser, or check all supported environments.
  2. Record a combination such as Ctrl + K, or use the manual builder on a phone, tablet, or desktop.
  3. Select Check shortcut to see deterministic results and up to three candidate combinations.
  4. Optionally save the shortcut to a Shortcut Set or My Shortcuts.

What this tool checks

The checker compares an exact normalized combination with the built-in, source-linked browser and operating-system records listed in its data coverage. It also checks the current shortcut set for duplicates and compares the combination with items you saved in My Shortcuts. It does not inspect installed software.

Understanding the result levels

Known conflict means an exact match exists in an official built-in source for the selected environment. Shortcut Set duplicate means the current active shortcut set already uses the combination. Used in your library reflects the scope you saved. Accessibility warnings and convention notes are guidance, not claims that the browser will always block the shortcut.

No known conflict found means only that the selected built-in sources, current shortcut set, and saved library did not produce a stronger result. It does not mean the shortcut is universally safe.

Why keyboard shortcuts conflict

Browsers, operating systems, desktop applications, extensions, accessibility tools, and websites can all respond to keyboard input. For example, Ctrl + K commonly focuses browser search, while Ctrl + Shift + P may open a browser or developer command. Context and operating system matter.

Checking shortcuts across browsers and operating systems

A combination can be reserved in one environment and available to page code in another. Command + 1 is commonly a browser tab shortcut on macOS, while Windows and Linux typically use Ctrl for the equivalent browser action. The checker keeps Command and Ctrl distinct when matching exact conflicts.

Using My Shortcuts

Add shortcuts from tools that are not in the built-in checker and give each item a scope. A system-wide shortcut is treated as a strong match. The same Alt + Shift + K assigned in an unrelated application is reported as already used elsewhere, not guaranteed to be a direct technical conflict. Export a JSON backup before clearing browser data or moving devices.

Keyboard shortcut accessibility

A single-character shortcut such as K can be triggered accidentally by speech input. If your web app uses character-only shortcuts, provide a way to turn them off, remap them with a non-character modifier, or limit them to a focused component. This is practical design guidance, not a legal-compliance claim. See W3C guidance on character key shortcuts.

Privacy and local storage

Your shortcut projects and saved shortcut list are processed locally in your browser and are not uploaded by this tool. They are stored in browser local storage. Clearing site data may delete them, so JSON backup export is recommended. You can delete all application data from My Shortcuts.

Site-level analytics and advertising services may make separate network requests under the Tweaknook Privacy Policy. They do not receive your shortcut project records from the tool logic.

Data coverage and methodology

Built-in records are exact shortcut matches from current official vendor documentation, reviewed on August 16, 2026. The internal validator checks IDs, required source fields, dates, severities, environments, and normalized combinations.

  • Chrome: Windows, macOS, Linux
  • Edge: Windows, macOS
  • Firefox: Windows, macOS, Linux
  • Safari: macOS
  • Windows system + accessibility
  • macOS system

Sources reviewed: Google Chrome Help, Microsoft Edge Support, Mozilla Support, Apple Safari Support, Microsoft Windows Support, Microsoft Windows Accessibility, and Apple Mac Support. Last data review: August 16, 2026.

Limitations

This does not include every installed application, browser extension, custom system setting, keyboard remapper, input method, or keyboard layout. Websites cannot inspect all of those sources. Browsers may also intercept a shortcut before the recorder receives it. Vendor shortcuts can change after the review date. Firefox 147+ can customize many defaults, Safari shortcuts can vary by keyboard layout, and Linux desktop/window-manager shortcuts are not exhaustively modeled because they vary by environment.

Frequently asked questions

Can this website detect every shortcut on my computer?

No. A website cannot inspect every installed program, extension, remapper, custom setting, input method, or layout.

Does this tool scan my installed applications?

No. It checks built-in source data and information you choose to save locally.

Where are my saved shortcuts stored?

Shortcut Sets, My Shortcuts items, and settings are stored in local storage for this site in your browser.

Can I move my shortcut library to another device?

Yes. Export a full JSON backup, transfer the file yourself, and import it on the other device.

What does “No known conflict found” mean?

No match was found in the selected built-in sources, current shortcut set, or relevant saved library items. It is not a guarantee.

Can I check multiple shortcuts at once?

Yes. Add shortcuts to a project, then use Check all.

Does the tool support Windows and macOS?

Yes, plus verified Chrome and Firefox records for Linux. Safari is available only with macOS.

Can I use the tool on a phone or tablet?

Yes. The manual builder is touch-friendly and does not require a physical keyboard.

Why are single-letter shortcuts flagged?

Speech input can accidentally trigger character-only commands. Make them disableable, remappable, or active only in a limited focus context.

Can I add shortcuts from programs that are not built into the checker?

Yes. Save them in My Shortcuts with an operating system, scope, and active or archived status.

About this Tweaknook tool

HotkeyRadar is published as part of Tweaknook's practical digital-work tools. Its conflict result combines documented built-in shortcut records with the shortcut sets and library items you enter in this browser. A reported match is a reason to review the assignment, not proof that every program on your computer will intercept it.

Before changing a production shortcut map, verify the final combination in the target application and environment. If you find an outdated built-in record or a tool bug, use the Contact page and include the operating system, browser, shortcut, and current vendor documentation when available.
